# 一江通海 · GitHub Pages 静态网页

本目录是一套可独立发布的纯静态网页：`index.html`、`style.css`、`app.js` 和 `assets/`。无需 npm、打包工具、数据库或服务器端程序。

## 发布

把本目录里的**全部文件和 `assets` 文件夹**一起放到 GitHub 仓库用于发布的目录中，使 `index.html` 与 `assets/` 处于同一级。配置 GitHub Pages 指向该目录后，打开生成的网页地址即可。只上传三个代码文件而不上传 `assets/` 会出现空白底图或缺少声音。

本地预览可直接打开 `index.html`；如果浏览器限制本地音频或资源读取，可用本地静态服务器打开本目录。例如在已安装 Python 的环境中，于本目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。网页本身不依赖 Python。

## 已包含的体验

- 五张底图组成横向推进的五幕长卷，保留上一幕、重看本幕和跳过动画。
- 第一幕小舟启程；第二幕小舟靠岸、货筐交接与推车入城；第三幕查看装载、搬运与收起跳板；第四幕扬帆远行；第五幕驶向江海、显示结语。
- 每幕一张主知识卡与两个可选热点卡。资料卡附原始来源链接；场景局部图是项目意象图，并非考古实物照片。
- 声音按钮控制水声、风声以及少量动作音效。音频在用户点击“开始行舟”后播放；系统选择减少动态效果时缩短位移动画。
- 键盘左右方向键可切换已解锁的幕，Esc 关闭知识卡；触屏可左右滑动切换已解锁的幕。

## 内容与素材说明

- 五幕场景、人物和船只是展陈叙事意象，不是朔门古港遗址或某艘历史船的考古复原。
- 知识卡正文改写自项目的《一江通海-知识卡与热点卡-资料稿.md》，来源链接直接列在弹窗内。网页没有使用尚未获授权的考古照片或媒体图片。
- 音频为此前素材包中的程序合成试听文件；正式发布前可以替换为审核后的音频。
- 第三幕码头的重绘遮挡候选图没有放进网页，因为它与原底图无法保证像素对位。网页将原底图的码头区域作为前景遮挡层复用，避免石块轮廓不一致；正式精修时仍应按船的最终停靠位置微调 `style.css` 中的 `.pier-cover` 裁切范围。
- `app.js` 中的 `SCENES` 数组可修改五幕文案、热点位置、来源和主操作。`style.css` 中 `.scene-1` 至 `.scene-5` 可修改各叠加层的位置、大小与动画距离。
